# 自定义导出与配色

2026-11-18 已实现。验收结果见 [ACCEPTANCE.md](ACCEPTANCE.md)。

## 导出设置

顶部“导出设置”打开原生浮层，选择分辨率和 24／25／30／50／60 fps。默认 1920×1080、30 fps；时长 5 秒、无音轨 H.264 MP4。

| 分组 | 分辨率 |
| --- | --- |
| 横屏 | 1280×720、1920×1080、2560×1440、3840×2160 |
| 竖屏 | 720×1280、1080×1920、1440×2560、2160×3840 |
| 手机长屏 | 1080×2400 |
| 自定义 | 正偶数整数宽高，输入后点击“应用” |

自定义输入先校验数值和 H.264 范围，再提交配置。帧率切换和预设选择直接生效。编码能力检查使用实际所选配置，导出画布检查设备的 WebGL 尺寸限制；不支持时显示具体原因。

预览按目标比例等比缩放，高度不超过 480 px。全景和跟随机位根据窄画幅后移；近景投影使用真实宽高比求解机位；结果牌同时约束横向和纵向尺寸。预览和导出共用同一构图函数与时间线。

## 配色设置

保留绿、蓝、紫三套快速预设。旁边的调色盘按钮打开自定义配色浮层，提供颜色选择器与六位 HEX 输入：

- 地胶、场外区域、背景、场线。
- 界内印记、界外印记、IN 结果、OUT 结果。

首次自定义从当前预设复制；切换预设后，自定义色板保留。编辑立即更新 SVG、CSS 和三维预览，保持播放位置与状态。场外、场线、印记和结果原有二维／三维展示色保留在预设中，用户修改同一用途时同步更新。

`setPalette` 更新材质、背景、雾、印记和结果牌纹理，不重建场景；被替换的纹理及时释放。自定义场线不改变球网和球体材质。

## 数据流与编码

设置控件 → 校验提交 → App 配置 → 编辑器／预览，以及 localStorage。

点击导出 → 复制回放输入、完整色板、宽高与 fps → 生成编码参数并检查能力 → 独立画布逐帧渲染 → H.264 编码 → MP4 封装 → 下载。

导出期间继续修改参数和颜色只影响界面和下一次导出。当前任务的画幅、颜色、总帧数和文件名均取点击时快照；保留单活动任务、取消、背压、封装和资源清理流程。

- 总帧数为 `5 × fps`，对应 120、125、150、250、300 帧。
- 采样时间 `i / fps`，时间戳 `round(i × 1_000_000 / fps)`，帧时长为相邻边界之差；末帧结束于 5,000,000 µs。
- 每秒一个关键帧。H.264 Baseline level 按宏块数、宏块率、单边宏块限制和码率选择。
- 码率以 1080p30 的 8 Mbps 为基线，按像素数与 fps 同比例计算，4K60 对应 64 Mbps。
- 文件名包含赛制、落点、宽高、fps 与本地时间。

浏览器记录导出参数、配色模式和自定义色板。首次使用采用默认配置；已有数据损坏或读取失败时，按用户要求静默重置，可写时覆盖原记录。禁用存储时设置在当前页面生效。
