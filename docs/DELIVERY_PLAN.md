# 开发规划

文档保存在本地，任务进度在 Multica 跟踪。

| 阶段 | 交付内容 | 完成标准 |
| --- | --- | --- |
| M1 选点与判定 | 标准球场、圆形落点精调、来球方向 | 能方便地设置压线/出界，判定正确 |
| M2 三维回放 | 飞行、落地特写、印记与结果 | 画面清楚、运镜自然，用户认可样片 |
| M3 视频与本地交付 | MP4 下载、运行说明、开源分发准备 | 按 README 可在本地运行并导出视频 |

先完成选点到最小回放的完整流程，再同时完善视觉和验证编码，最后完成视频导出和使用验收。

## 核心验收场景

- 场内、部分压线、外沿相切、完全出界、角落相交。
- 同一落点在单打和双打下的不同结果。
- 相同方向不同距离的输入产生相同回放。
- 四边与四角的落地关系清楚，明显界内外的位置有空间参照。
- 预览与视频中的触地点、圆形印记、结果和时长一致。
- 导出完成、取消后重试均可正常使用。
- 新用户按照 README 安装、启动并完成一次视频导出。

## 样片确认

确认接触圆大小、选点体验、镜头节奏和视频规格。初始建议见 PRD。

样片需覆盖三类落点：边线相切/完全出界、角落、明显界内。逐项记录结论，确认后回填 PRD 的初始建议；未确认前不得视为验收通过。

| 检查项 | 方法 | 记录 | 状态 |
| --- | --- | --- | --- |
| 接触半径 13 mm | 与 40 mm 白线同屏比较比例，判断压线与出界的可读性 | 样片链接 + 结论 | 未确认 |
| 镜头节奏 5 s 四段 | 连续观看，确认方向、飞行与结果都能读出 | 样片链接 + 结论 | 未确认 |
| 视频规格 | 检查导出文件的分辨率、帧率、时长与音轨 | 文件属性 + 播放结论 | 未确认 |
| 场地参照 | 远离边界时仍能辨认落点在球场中的位置 | 样片链接 + 结论 | 未确认 |

记录入口：本表。每次确认填写样片链接、结论与日期。
