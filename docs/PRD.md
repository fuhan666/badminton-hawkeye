# 羽毛球鹰眼模拟器

一个供用户本地运行的开源工具：在球场俯瞰图上设置落点和来球方向，生成转播鹰眼风格的三维回放并导出视频。

## 使用流程

1. 选择单打或双打，查看标准球场线和球网。
2. 点击放置固定圆形接触区域，在局部放大视图中拖动微调，制作压线或出界落点。
3. 选择来向点，箭头以落点为起点指向来向点，作为来向指示。第二点只决定方向。
4. 预览三维回放，调整选点后重新播放。
5. 导出视频到本地。

## 判定规则

- 有效区域是对应单打或双打的完整场地外边界矩形，包含白线。
- 接触圆与有效区域相交或相切为 IN，完全分离为 OUT。
- 编辑图、判定和视频印记共用同一个圆心与半径。
- 来球方向只影响动画。相同方向、不同距离的来向点生成相同回放。
- 切换单打/双打保留选点并更新判定。

## 界面

球场编辑器、局部放大视图和视频预览构成主界面。操作保留赛制切换、播放、重新选点和导出，布局清晰、视觉克制。

球场四周留出场外选点空间。放大视图按真实比例显示接触圆和白线；全场图使用便于拖动的手柄。落点和有效方向齐备后启用播放与导出；两点重合时提示调整来向点。

布局草图（左 2/3 选点，右 1/3 精调与预览）：

```
┌─────────────────────────────────┬───────────────────────────────────┐
│ 赛制：单打 / 双打      播放   重新选点   导出视频                   │
├─────────────────────────────────┼───────────────────────────────────┤
│ 全场俯瞰（含 1 m 场外可选区）   │ 局部精调 · 等比放大               │
│                                 │ ┌──────────────────────────────┐  │
│      ┌───────────────┐          │ │ 白线       ● 落点圆          │  │
│      │               │          │ │      ─────────────           │  │
│      │   球场 + 网   │          │ └──────────────────────────────┘  │
│      │               │          │ 判定：IN / OUT                    │
│      └───────────────┘          ├───────────────────────────────────┤
│                                 │ 视频预览                          │
│  落点 ● ─────→ ○ 来向           │ ┌──────────────────────────────┐  │
│                                 │ │   16:9 回放画面              │  │
│                                 │ └──────────────────────────────┘  │
└─────────────────────────────────┴───────────────────────────────────┘
```

交互口径：

- 全场图与局部视图共用同一份米制坐标，拖动任一视图后另一视图同步，缩放不改变落点数值。
- 全场图的手柄可以放大以便点选，但不改变接触半径；局部视图按真实比例绘制接触圆，压线与相切的差别在局部视图里看得清。
- 来向箭头由落点指向来向点，只作来向指示；飞行方向仍取 `落点 - 来向点`，两点都可再次拖动。来向点只决定方向，同方向不同距离产生相同输入。
- 两点重合时阻止播放与导出，并提示调整来向点；切换单打/双打保留两个点，只更新判定与线框。

## 视频

分镜：球场全景 → 飞行跟随 → 落地慢放 → 圆形印记与 IN/OUT 定格。

球托底端落到圆心，球体淡出后留下接触印记。镜头根据落点构图：边线附近看清对应白线，角落看清两条白线，远离边界时保留球场参照。

四段镜头草图：

```
① 全景 0–0.8 s             ② 跟随 0.8–2.0 s
   ╭────────────────╮         ╭────────────────╮
   │  ●·····        │         │   ●→           │
   │ ╱  球场俯瞰    │         │     ╲  球体    │
   ╰────────────────╯         ╰────────────────╯

③ 慢放触地 2.0–3.6 s       ④ 定格 3.6–5.0 s
   ╭────────────────╮         ╭────────────────╮
   │ ────●────      │         │ ────◉────      │
   │   贴地低机位   │         │    [ IN ]      │
   ╰────────────────╯         ╰────────────────╯
```

| 段 | 建议时段 | 镜头意图 |
| --- | --- | --- |
| 全景 | 0–0.8 s | 高角度俯瞰，交代落点所在半场与来球方向 |
| 跟随 | 0.8–2.0 s | 侧后方跟随球体，看清球托朝向与飞行弧线，网与边线保持可辨 |
| 慢放触地 | 2.0–3.6 s | 贴地低机位慢放到触地，球托底端落在圆心；边线附近对准对应白线，角落同时容纳两条线 |
| 定格 | 3.6–5.0 s | 球体淡出，圆形印记与 IN/OUT 同屏，镜头轻微前推保持压迫感 |

时段是待样片调整的初始建议，不是验收数值。

初始建议：接触半径 13 mm；约 5 秒、1920×1080、30 fps、无音轨 MP4。半径为模拟参数，以上均为初始建议，需通过样片确认后回填本文件与开发规划中的确认记录。

### 转播参考

- BWF TV《Badminton Unlimited 2019 | BWF Special Feature - Hawkeye》<https://www.youtube.com/watch?v=sF5lGslGY_0>：封面帧为多机位光学追踪的相机与镜头组。可借鉴的是转播鹰眼用多机位定位建立三维轨迹，本项目只需还原其呈现方式，不需要真实光学追踪。
- Shuttle Flash《Badminton HAWKEYE Unforgettable Challenges》<https://www.youtube.com/watch?v=zeYDxn5JdYE>：封面帧把画面压到单条白线尺度，白线一侧一个实心圆点，画面下方独立「IN」结果牌。可借鉴三点：触地后镜头压近到单线尺度、接触点用实心圆而不是十字、结果以独立牌面呈现且与画面同屏。

两条参考只核对了标题、发布方与封面帧，没有逐段观摩视频；具体时间定位与镜头序列留待三维样片阶段补充。转播素材不入库，也不随项目分发。

## 验收

用户能够顺畅完成选点、精调、预览和下载。压线、相切、角落和完全出界的判定正确；回放触地点与选点一致；导出视频与预览一致且可播放。

接触半径与视频规格的样片确认尚未完成，见开发规划的样片确认记录。
