# 产品需求

本地运行的羽毛球落点与三维回放工具。用户设置落点和来球方向，查看界内／界外判定，生成回放视频。

## 使用流程

选择赛制 → 放置落点 → 设置来向点 → 精调并查看判定 → 预览 → 导出视频。

| 区域 | 内容 |
| --- | --- |
| 顶部 | 赛制、配色、导出设置和导出视频 |
| 全场俯瞰 | 标准球场与场网、落点／来向点切换、清除来向点 |
| 局部精调 | 接触圆与场线的等比放大、IN／OUT、落点毫米坐标 |
| 三维回放 | 所选画幅的预览、播放／暂停、重播和时间轴 |

桌面采用左右两栏，左侧选点，右侧精调与回放；窄屏按可用宽度排列。页面文案保留操作名称、必要数据和状态反馈，通过布局、选中状态及手柄颜色表达操作关系。

## 选点与判定

- 有效区域采用完整单打或双打场地的外边界矩形，白线计入界内，发球线作为位置参照。
- 接触圆与有效区域相交或相切为 IN，完全分离为 OUT。编辑器、判定与视频印记共用圆心和半径。
- 接触半径固定为 13 mm，是模拟参数。
- 全场图四周留出 1 m 场外选点空间，使用放大的手柄便于点选；局部视图按真实比例显示接触圆与场线。
- 两个视图同步更新选点。方向键每次微调 1 mm，Shift 加方向键为 10 mm；快捷键提示在视图聚焦时显示。
- 来向点只决定方向，同方向、不同距离的来向点生成相同回放。指示箭头由落点指向来向点，球体从来向点一侧飞向落点。
- 缺少来向点或两点距离小于 10 mm 时提示调整，并禁用播放和导出。
- 切换赛制保留选点，更新有效边界与判定；改变赛制或选点后，回放暂停并回到起点。

## 回放

球托底端在 3.2 秒触地，位置与落点圆心一致；球体淡出后保留接触印记与 IN／OUT。

| 时段 | 画面 |
| --- | --- |
| 0–0.8 s | 全景，交代球场位置与来球方向 |
| 0.8–2.0 s | 跟随球体飞行 |
| 2.0–3.6 s | 慢放触地，呈现接触点与参照线 |
| 3.6–5.0 s | 印记与判定定格 |

镜头依据落点与画幅构图：边线附近包含对应场线，角落包含两条场线，远离边界时保留场内参照。预览与导出共用画幅和时间线。

接触半径、印记观感和镜头节奏采用上述模拟参数，视觉效果尚未记录项目所有者的最终确认，样片见[验收记录](ACCEPTANCE.md)。

## 导出与配色

视频为 H.264 MP4，固定 5 秒，无音轨；默认 1920×1080、30 fps。

| 尺寸选项 | 分辨率 |
| --- | --- |
| 横屏 | 1280×720、1920×1080、2560×1440、3840×2160 |
| 竖屏 | 720×1280、1080×1920、1440×2560、2160×3840 |
| 手机长屏 | 1080×2400 |
| 自定义 | 正偶数宽高，输入后点击「应用」 |

帧率可选 24、25、30、50、60 fps。导出检查所选配置的编码能力与设备画布限制，不支持时显示具体原因。

配色提供绿色、蓝色、紫色预设，以及地胶、场外区域、背景、场线、界内印记、界外印记、IN 结果和 OUT 结果八项自定义颜色。首次自定义从当前预设复制，切换预设后保留自定义色板。换色即时更新编辑器和预览，保留播放位置与状态。

导出参数和配色保存在当前浏览器。导出任务使用点击时的选点、完整色板和视频参数；导出过程中可以继续编辑，同时只允许一个活动任务。界面提供进度、取消和结果反馈，取消后可重新导出。

## 验收

验证选点、精调、预览和下载完整流程，覆盖场内、压线、相切、角落、完全出界、赛制切换及方向一致性。导出检查触地点、印记、判定、画幅、时长与预览一致，并可实际播放。

验证方法、结果与视觉评估分别记录在[验收记录](ACCEPTANCE.md)中。
